## 🚀 كيفية التشغيل:

### 1. اختبر الـ APIs
```bash
# افتح هذا الرابط في Browser
http://localhost:3000/api/seed

# أو استخدم curl
curl http://localhost:3000/api/seed
```

### 2. اذهب إلى الـ Admin
```
http://localhost:3000/admin/login
Email: admin@khaled.com
Password: 12345678
```

### 3. أضف Project جديد
1. اضغط على "Projects"
2. اضغط "Add Project"
3. ملأ البيانات والصور
4. اضغط "Save"

### 4. شوف النتيجة في الـ Homepage
اذهب إلى `http://localhost:3000` وشوف الـ Project الجديد بتظهر! ✅
